01 · The problem

What does Kruskal solve?

Kruskal’s algorithm finds a minimum spanning tree: the lowest-total-weight set of links that connects every vertex without cycles.

A greedy algorithm for weighted, undirected graphs
Purpose

Connect locations at minimum total cost.

Examples

Road, cable, or utility network planning.

Disconnected graph

Returns a minimum spanning forest, one tree per component.

02 · The greedy rule

Take the lightest safe edge

Process edges by weight. Add an edge when it joins two components; skip it when it would create a cycle.

1 · OrderConsider edges from least to greatest weight.
2 · CheckAre the endpoints already connected?
3 · Keep or skipJoin different components; avoid cycles.
4 · FinishStop at V−1 accepted edges for a connected graph.
Time: vanilla O(E log E) · radix O(E) for fixed-width weights · DSU adds O(E α(V)) to both.   Space: both O(E+V); radix has an extra O(E) buffer.
